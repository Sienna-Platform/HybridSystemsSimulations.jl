Calculate hosting capacity for a hybrid system

How to calculate how much constant, must-serve load $L_{\mathrm{op}}$ can be added at a single node behind a hybrid point of common coupling (PCC) using HybridHostingCapacityDispatch.

When to use

Use this formulation when you have a PowerSystems.System with a candidate bus and want a single unit commitment / economic-dispatch solve that maximizes constant, must-serve load, $L_{\mathrm{op}}$, for a PowerSystems.HybridSystem at that bus. The optimal value $L_{\mathrm{op}}^*$ is reported in MW via LOpVariable.

Must-serve electric load and PCC import/export rating co-scale with the same decision (see the HybridHostingCapacityDispatch docstring):

P_ld(t) = σ(t) * L_op
0 ≤ p_in(t), p_out(t) ≤ L_op

with reservation status using the fixed device-model attribute "l_op_ub" (not $u \cdot L_{\mathrm{op}}$). Onsite generation and storage nameplates stay fixed while load and PCC limits move with $L_{\mathrm{op}}$.

Prerequisites

  • A PowerSystems.System with time series covering the decision horizon (this walkthrough uses the modified RTS-GMLC DA system from PowerSystemCaseBuilder.jl).
  • An MIP-capable solver (this walkthrough uses HiGHS).
  • Device-model attribute "l_op_ub" in SYSTEM_BASE pu (typically base_power $= 100$ MW → $50$ MW is $0.5$ pu).
  • Zero renewable curtailment cost when $L_{\mathrm{op}}$ must dominate the objective. PowerSimulations.jl minimizes cost; the formulation adds a negative unit benefit on $L_{\mathrm{op}}$, so nonzero curtailment cost can undercut that term.

Co-located hybrid walkthrough

Wind, combined-cycle gas, EnergyReservoirStorage, and a PowerSystems.PowerLoad behind one PCC at bus "Chuhsi" on the modified RTS-GMLC DA system. Nameplates for onsite renewable / thermal / storage are fixed. Electric load and PCC limits co-scale with $L_{\mathrm{op}}$. The walkthrough reuses the existing Clark load from the RTS case (unit-normalized $\sigma(t)$; see HybridHostingCapacityDispatch).

Construct the hybrid and set $L_{\mathrm{op}}$ upper bound

add_component! copies subcomponent time series onto the hybrid. Device limits and "l_op_ub" are SYSTEM_BASE pu.

hybrid = PSY.HybridSystem(;
    name = string(bus.number) * "_Hybrid",
    available = true,
    status = true,
    bus = bus,
    active_power = 1.0,
    reactive_power = 0.0,
    base_power = 100.0,
    operation_cost = PSY.MarketBidCost(nothing),
    thermal_unit = thermal,
    electric_load = load,
    storage = bat,
    renewable_unit = renewable,
    interconnection_impedance = 0.0 + 0.0im,
    interconnection_rating = nothing,
    input_active_power_limits = (min = 0.0, max = 10.0),
    output_active_power_limits = (min = 0.0, max = 10.0),
    reactive_power_limits = nothing,
)
add_component!(sys, hybrid)

hybrid = first(get_components(HybridSystem, sys))
l_op_ub_pu = Float64(PSY.get_output_active_power_limits(hybrid).max)
10.0

Build the problem template

Register HybridHostingCapacityDispatch via a PowerSimulations.DeviceModel on a PowerSimulations.ProblemTemplate with a UC + DC PowerSimulations.NetworkModel.

template = ProblemTemplate(
    NetworkModel(
        DCPPowerModel;
        use_slacks = true,
        duals = [NodalBalanceActiveConstraint],
    ),
)
set_device_model!(template, ThermalStandard, ThermalStandardUnitCommitment)
set_device_model!(template, RenewableDispatch, RenewableFullDispatch)
set_device_model!(template, RenewableNonDispatch, FixedOutput)
set_device_model!(template, PowerLoad, StaticPowerLoad)
set_device_model!(template, Line, StaticBranch)
set_device_model!(template, TapTransformer, StaticBranchUnbounded)
set_service_model!(template, ServiceModel(VariableReserve{ReserveUp}, RangeReserve))
set_service_model!(template, ServiceModel(VariableReserve{ReserveDown}, RangeReserve))

set_device_model!(
    template,
    DeviceModel(
        PSY.HybridSystem,
        HybridHostingCapacityDispatch;
        attributes = Dict{String, Any}(
            "l_op_ub" => l_op_ub_pu,
            "cycling" => false,
            "regularization" => false,
            "reservation" => true,
            "energy_target" => false,
        ),
    ),
)

Solve and read $L_{\mathrm{op}}$

Build and solve a DecisionModel, then read LOpVariable (values are in MW).

model = DecisionModel(
    template,
    sys;
    optimizer = optimizer,
    store_variable_names = true,
)
PSI.build!(model; output_dir = output_dir)
PSI.solve!(model)

res = PSI.OptimizationProblemResults(model)
lop_df = PSI.read_variable(res, "LOpVariable__HybridSystem")
lop_mw = Float64(first(lop_df[!, :value]))
lop_mw
